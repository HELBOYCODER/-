# صندوق (Sandogh) — گاوصندوق رمزنگاری‌شده با قفل چرخشی

اپ اندروید که با یک قفل چرخشی قدیمی (صدای مکانیکی واقعی) باز می‌شود و فایل‌های
خصوصی را رمزگذاری‌شده نگه می‌دارد؛ فایل‌ها بعد از افزودن از گالری و فایل‌منیجر پاک
می‌شوند.

## قابلیت‌ها
- **قفل چرخشی**: روی عدد مخفی (پیش‌فرض `666`) بمان تا باز شود. صدای تیک چرخش و صدای
  باز شدن مکانیزم با Web Audio ساخته شده (بدون فایل صوتی، آفلاین).
- **انتقال و مخفی‌سازی**: عکس/ویدیو/صدا/سند را انتخاب کن؛ کپی + رمزگذاری AES-256
  داخل حافظه خصوصی اپ و حذف نسخه اصلی.
- **رمزگذاری**: کلید با PBKDF2 از کد قفل مشتق می‌شود. بدون کد، فایل‌ها خوانده نمی‌شوند.
- **نمایشگر داخلی**: عکس، ویدیو، موزیک داخل اپ؛ اسناد (PDF…) با رمزگشایی موقت.
- **ضد اسکرین‌شات** (`FLAG_SECURE`) و **قفل خودکار** هنگام خروج از اپ.

## تغییر کد قفل
کد مخفی داخل `app/src/main/assets/lock.html` خط `var TARGET = 666;` است.
همان کد، کلید رمزگذاری را می‌سازد — اگر بعد از افزودن فایل عوضش کنی، فایل‌های قبلی
باز نمی‌شوند.

## بیلد با GitHub Actions
1. این پوشه را به یک ریپوی گیت‌هاب push کن (شاخه `main`).
2. تب **Actions** → ورک‌فلوی **Build APK** خودکار اجرا می‌شود.
3. از بخش **Artifacts** فایل `sandogh-debug-apk` را دانلود کن؛ داخلش APK هست.
4. روی گوشی نصب کن (نصب از منابع ناشناس را فعال کن).

بیلد محلی هم ممکن است: `gradle assembleDebug` (یا با Android Studio).

## دسترسی حذف کامل
برای حذف قطعی نسخه اصلی از همه‌جا، در اندروید ۱۱ به بالا دسترسی «مدیریت همه فایل‌ها»
لازم است؛ اپ موقع نیاز از تو می‌خواهد. بدون آن، بیشتر فایل‌ها حذف می‌شوند ولی بعضی
فایل‌های گالری ممکن است دستی نیاز به حذف داشته باشند.

## نکات امنیتی
- فایل‌ها رمزگذاری‌شده‌اند و در حافظه خصوصی اپ‌اند (در گالری/فایل‌منیجر دیده نمی‌شوند).
- با **حذف اپ**، گاوصندوق هم پاک می‌شود — پشتیبان بگیر.
- کد `666` ساده است؛ برای امنیت جدی یک کد طولانی‌تر در `TARGET` بگذار.

```
app/src/main/java/ir/ersaz/sandogh/
  LockActivity.kt                    صفحه قفل و پل JS→بومی
  VaultActivity.kt                   گرید گاوصندوق + ایمپورت
  ViewerActivity.kt                  نمایش عکس/ویدیو/صدا/سند
  Crypto.kt                          AES-256-CBC + PBKDF2
  ImportHelper.kt                    کپی+رمز+حذف نسخه اصلی
  VaultStore.kt / VaultItem.kt       مخزن و ایندکس
  PathResolver.kt / Permissions.kt   مسیر فایل و دسترسی
```
